# 吉方位神社仏閣プランナー 2 次開発要件（Phase 2）

## 1. ゴールと制約

- **目的**  
  1 次開発（MVP）で実装された基本機能を拡張し、実用的なアプリケーションとして完成させる。

- **対象機能**

  1. 地図表示機能の実装（Google Maps 統合）
  2. 検索履歴・お気に入り機能の実装（データベース連携）
  3. UI/UX の改善（レスポンシブ対応、ローディング、エラーハンドリング）

- **前提条件**

  - 1 次開発で実装済みの機能は動作していること
  - データベース（SearchHistory、Favorite）は既にスキーマ定義済み
  - Google Maps API キーは取得済み

- **制約**
  - 既存の API エンドポイントとの互換性を維持
  - 1 次開発で実装された機能を破壊しない
  - モバイル対応は基本的なレスポンシブ対応まで（ネイティブアプリ化は対象外）

## 2. 機能要件

### 2.1 地図表示機能

#### 2.1.1 基本機能

- **Google Maps JavaScript API 統合**

  - 地図の初期表示（現在地を中心）
  - 検索結果の神社・寺院にマーカーを配置
  - マーカーのクリックで詳細情報を表示

- **地図の表示要件**

  - 中心座標：ユーザー入力住所の座標（`center`）
  - ズームレベル：検索半径に応じて自動調整
  - 地図タイプ：通常の地図表示（roadmap）

- **マーカーの表示要件**
  - 各候補神社・寺院にマーカーを配置
  - マーカーの色分け：吉方位ごとに異なる色（例：N=青、E=緑、SE=黄、NW=紫）
  - マーカーに番号を表示（テーブルの行番号と対応）
  - マーカークリックで情報ウィンドウ（InfoWindow）を表示
    - 名称
    - 住所
    - 方位
    - 距離
    - お気に入り登録ボタン

#### 2.1.2 インタラクション機能

- **地図とテーブルの連動**

  - テーブルの行をクリック/ホバー → 対応するマーカーをハイライト
  - マーカーをクリック → テーブルの該当行をスクロールしてハイライト

- **地図の操作**
  - ドラッグで移動可能
  - ズームイン/アウト可能
  - 地図の中心移動時に検索範囲を再表示（オプション）

#### 2.1.3 技術実装

- **フロントエンド**

  - `@react-google-maps/api` または `@vis.gl/react-google-maps` を使用
  - React コンポーネントとして実装（`MapDisplay.tsx`）
  - 地図の初期化は検索結果取得後に実行

- **API キー管理**
  - フロントエンドの環境変数（`VITE_GOOGLE_MAPS_API_KEY`）から取得
  - または、バックエンド経由で API キーを提供（推奨）

### 2.2 検索履歴・お気に入り機能

#### 2.2.1 検索履歴機能

- **検索履歴の保存**

  - 検索実行時に自動的に履歴を保存
  - 保存内容：
    - 生年月日（`birthDate`）
    - 住所（`address`）
    - 対象年月（`yearMonth`）
    - 検索半径（`radiusKm`）
    - 算出された本命星（`honmeisei`）
    - 作成日時（`createdAt`）

- **検索履歴の表示**

  - サイドバーまたはモーダルで履歴一覧を表示
  - 最新順に表示（最大 20 件）
  - 各履歴項目に以下を表示：
    - 検索日時
    - 住所
    - 対象年月
    - 本命星
    - 「再検索」ボタン
    - 「削除」ボタン

- **検索履歴からの再検索**
  - 履歴項目をクリック → フォームに値を復元
  - 「再検索」ボタンで同じ条件で再検索実行

#### 2.2.2 お気に入り機能

- **お気に入りの登録**

  - 検索結果のテーブル各行に「お気に入り」ボタンを追加
  - マーカーの InfoWindow にも「お気に入り」ボタンを追加
  - クリックでお気に入りに追加/削除（トグル）

- **お気に入りの表示**

  - 専用ページまたはモーダルでお気に入り一覧を表示
  - 各お気に入り項目に以下を表示：
    - 神社・寺院名
    - 住所
    - 方位
    - 距離
    - 登録日時
    - 「地図で表示」ボタン
    - 「削除」ボタン

- **お気に入りの管理**
  - お気に入り一覧から削除可能
  - お気に入り登録時に検索履歴 ID を紐付け

#### 2.2.3 バックエンド API

- **`POST /api/history`**

  - 検索履歴を保存
  - 入力：
    ```json
    {
      "birthDate": "1978-03-10",
      "address": "東京都渋谷区",
      "yearMonth": "2025-02",
      "radiusKm": 20,
      "honmeisei": "四緑木星"
    }
    ```
  - 出力：
    ```json
    {
      "id": 1,
      "createdAt": "2025-01-15T10:30:00Z"
    }
    ```

- **`GET /api/history`**

  - 検索履歴一覧を取得
  - クエリパラメータ：`?limit=20`
  - 出力：
    ```json
    {
      "histories": [
        {
          "id": 1,
          "birthDate": "1978-03-10",
          "address": "東京都渋谷区",
          "yearMonth": "2025-02",
          "radiusKm": 20,
          "honmeisei": "四緑木星",
          "createdAt": "2025-01-15T10:30:00Z"
        }
      ]
    }
    ```

- **`DELETE /api/history/:id`**

  - 検索履歴を削除

- **`POST /api/favorites`**

  - お気に入りを追加
  - 入力：
    ```json
    {
      "searchHistoryId": 1,
      "name": "渋谷氷川神社",
      "address": "東京都渋谷区...",
      "lat": 35.6581,
      "lng": 139.7013,
      "direction8": "N",
      "distanceKm": 1.81
    }
    ```

- **`GET /api/favorites`**

  - お気に入り一覧を取得
  - 出力：
    ```json
    {
      "favorites": [
        {
          "id": 1,
          "name": "渋谷氷川神社",
          "address": "東京都渋谷区...",
          "lat": 35.6581,
          "lng": 139.7013,
          "direction8": "N",
          "distanceKm": 1.81,
          "createdAt": "2025-01-15T10:35:00Z"
        }
      ]
    }
    ```

- **`DELETE /api/favorites/:id`**
  - お気に入りを削除

## 11. 吉方位の動的計算機能（Phase 2 拡張）

### 11.1 背景と課題

現在の実装では、吉方位は本命星ごとに固定値のテーブルで管理されており、年月によって変化しません。しかし、九星気学では年盤・月盤が毎年・毎月変化するため、実際の吉方位は時期によって異なります。

**現状の問題点：**

- `LUCKY_DIRECTIONS_TABLE` が固定値
- `yearMonth` パラメータが未使用
- 本命星のみで判定し、年盤・月盤を考慮していない

### 11.2 九星気学の基本ロジック

#### 11.2.1 年盤の算出

年盤とは、その年に各方位に配置される九星のことです。

**年盤中宮の計算式：**

```
年盤中宮 = 11 - (年の各桁の和を一桁にした値)
```

例：

- 2025 年 → 2+0+2+5 = 9 → 11 - 9 = 2（二黒土星が中宮）
- 2024 年 → 2+0+2+4 = 8 → 11 - 8 = 3（三碧木星が中宮）

**注意：立春補正**

- 九星気学では立春（2 月 4 日頃）を年の始まりとする
- 1 月 1 日〜立春前日までは前年の年盤を使用
- 本実装では簡易的に 2 月 4 日を基準とする

#### 11.2.2 月盤の算出

月盤とは、その月に各方位に配置される九星のことです。

**月盤中宮の計算表：**

| 年盤中宮       | 2 月 | 3 月 | 4 月 | 5 月 | 6 月 | 7 月 | 8 月 | 9 月 | 10 月 | 11 月 | 12 月 | 1 月 |
| -------------- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ----- | ----- | ----- | ---- |
| 一白/四緑/七赤 | 8    | 7    | 6    | 5    | 4    | 3    | 2    | 1    | 9     | 8     | 7     | 6    |
| 二黒/五黄/八白 | 5    | 4    | 3    | 2    | 1    | 9    | 8    | 7    | 6     | 5     | 4     | 3    |
| 三碧/六白/九紫 | 2    | 1    | 9    | 8    | 7    | 6    | 5    | 4    | 3     | 2     | 1     | 9    |

#### 11.2.3 方位盤の配置

九星は以下のように 8 方位と中央に配置されます（後天定位盤）：

```
   SE    S    SW
    4    9    2

E   3   [5]   7   W

    8    1    6
   NE    N    NW
```

年盤・月盤の中宮が決まったら、上記の配置を基準に各方位の九星を算出します。

**算出ロジ �� ク：**

```
方位の九星 = (中宮の九星 + 方位オフセット - 1) % 9 + 1
※ ただし、結果が0の場合は9、10の場合は1とする
```

方位オフセット：

- 北（N）: 0
- 北東（NE）: 7
- 東（E）: 2
- 南東（SE）: 3
- 南（S）: 8
- 南西（SW）: 1
- 西（W）: 6
- 北西（NW）: 5

#### 11.2.4 吉方位の判定ロジック

**吉方位の条件：**

1. **本命星との相性（五行の相生）**

   - 木性（三碧・四緑）: 水性（一白）が吉、木性も吉、火性（九紫）も可
   - 火性（九紫）: 木性（三碧・四緑）が吉、火性も可
   - 土性（二黒・五黄・八白）: 火性（九紫）が吉、土性も可
   - 金性（六白・七赤）: 土性（二黒・五黄・八白）が吉、金性も可
   - 水性（一白）: 金性（六白・七赤）が吉、水性も可

2. **凶方位の除外**
   - **五黄殺**: 五黄土星が位置する方位
   - **暗剣殺**: 五黄土星の正反対の方位
   - **本命殺**: 本命星が位置する方位
   - **本命的殺**: 本命星の正反対の方位

**簡易判定ロジック（プロトタイプ版）：**

- 年盤・月盤の両方で本命星と相性の良い九星が配置されている方位
- 五黄殺・暗剣殺を除外
- 本命殺・本命的殺を除外

# 吉方位神社仏閣プランナー 2 次開発要件（Phase 2）

## 1. ゴールと制約

- **目的**  
  1 次開発（MVP）で実装された基本機能を拡張し、実用的なアプリケーションとして完成させる。

- **対象機能**

  1. 地図表示機能の実装（Google Maps 統合）
  2. 検索履歴・お気に入り機能の実装（データベース連携）
  3. UI/UX の改善（レスポンシブ対応、ローディング、エラーハンドリング）

- **前提条件**

  - 1 次開発で実装済みの機能は動作していること
  - データベース（SearchHistory、Favorite）は既にスキーマ定義済み
  - Google Maps API キーは取得済み

- **制約**
  - 既存の API エンドポイントとの互換性を維持
  - 1 次開発で実装された機能を破壊しない
  - モバイル対応は基本的なレスポンシブ対応まで（ネイティブアプリ化は対象外）

## 2. 機能要件

### 2.1 地図表示機能

#### 2.1.1 基本機能

- **Google Maps JavaScript API 統合**

  - 地図の初期表示（現在地を中心）
  - 検索結果の神社・寺院にマーカーを配置
  - マーカーのクリックで詳細情報を表示

- **地図の表示要件**

  - 中心座標：ユーザー入力住所の座標（`center`）
  - ズームレベル：検索半径に応じて自動調整
  - 地図タイプ：通常の地図表示（roadmap）

- **マーカーの表示要件**
  - 各候補神社・寺院にマーカーを配置
  - マーカーの色分け：吉方位ごとに異なる色（例：N=青、E=緑、SE=黄、NW=紫）
  - マーカーに番号を表示（テーブルの行番号と対応）
  - マーカークリックで情報ウィンドウ（InfoWindow）を表示
    - 名称
    - 住所
    - 方位
    - 距離
    - お気に入り登録ボタン

#### 2.1.2 インタラクション機能

- **地図とテーブルの連動**

  - テーブルの行をクリック/ホバー → 対応するマーカーをハイライト
  - マーカーをクリック → テーブルの該当行をスクロールしてハイライト

- **地図の操作**
  - ドラッグで移動可能
  - ズームイン/アウト可能
  - 地図の中心移動時に検索範囲を再表示（オプション）

#### 2.1.3 技術実装

- **フロントエンド**

  - `@react-google-maps/api` または `@vis.gl/react-google-maps` を使用
  - React コンポーネントとして実装（`MapDisplay.tsx`）
  - 地図の初期化は検索結果取得後に実行

- **API キー管理**
  - フロントエンドの環境変数（`VITE_GOOGLE_MAPS_API_KEY`）から取得
  - または、バックエンド経由で API キーを提供（推奨）

### 2.2 検索履歴・お気に入り機能

#### 2.2.1 検索履歴機能

- **検索履歴の保存**

  - 検索実行時に自動的に履歴を保存
  - 保存内容：
    - 生年月日（`birthDate`）
    - 住所（`address`）
    - 対象年月（`yearMonth`）
    - 検索半径（`radiusKm`）
    - 算出された本命星（`honmeisei`）
    - 作成日時（`createdAt`）

- **検索履歴の表示**

  - サイドバーまたはモーダルで履歴一覧を表示
  - 最新順に表示（最大 20 件）
  - 各履歴項目に以下を表示：
    - 検索日時
    - 住所
    - 対象年月
    - 本命星
    - 「再検索」ボタン
    - 「削除」ボタン

- **検索履歴からの再検索**
  - 履歴項目をクリック → フォームに値を復元
  - 「再検索」ボタンで同じ条件で再検索実行

#### 2.2.2 お気に入り機能

- **お気に入りの登録**

  - 検索結果のテーブル各行に「お気に入り」ボタンを追加
  - マーカーの InfoWindow にも「お気に入り」ボタンを追加
  - クリックでお気に入りに追加/削除（トグル）

- **お気に入りの表示**

  - 専用ページまたはモーダルでお気に入り一覧を表示
  - 各お気に入り項目に以下を表示：
    - 神社・寺院名
    - 住所
    - 方位
    - 距離
    - 登録日時
    - 「地図で表示」ボタン
    - 「削除」ボタン

- **お気に入りの管理**
  - お気に入り一覧から削除可能
  - お気に入り登録時に検索履歴 ID を紐付け

#### 2.2.3 バックエンド API

- **`POST /api/history`**

  - 検索履歴を保存
  - 入力：
    ```json
    {
      "birthDate": "1978-03-10",
      "address": "東京都渋谷区",
      "yearMonth": "2025-02",
      "radiusKm": 20,
      "honmeisei": "四緑木星"
    }
    ```
  - 出力：
    ```json
    {
      "id": 1,
      "createdAt": "2025-01-15T10:30:00Z"
    }
    ```

- **`GET /api/history`**

  - 検索履歴一覧を取得
  - クエリパラメータ：`?limit=20`
  - 出力：
    ```json
    {
      "histories": [
        {
          "id": 1,
          "birthDate": "1978-03-10",
          "address": "東京都渋谷区",
          "yearMonth": "2025-02",
          "radiusKm": 20,
          "honmeisei": "四緑木星",
          "createdAt": "2025-01-15T10:30:00Z"
        }
      ]
    }
    ```

- **`DELETE /api/history/:id`**

  - 検索履歴を削除

- **`POST /api/favorites`**

  - お気に入りを追加
  - 入力：
    ```json
    {
      "searchHistoryId": 1,
      "name": "渋谷氷川神社",
      "address": "東京都渋谷区...",
      "lat": 35.6581,
      "lng": 139.7013,
      "direction8": "N",
      "distanceKm": 1.81
    }
    ```

- **`GET /api/favorites`**

  - お気に入り一覧を取得
  - 出力：
    ```json
    {
      "favorites": [
        {
          "id": 1,
          "name": "渋谷氷川神社",
          "address": "東京都渋谷区...",
          "lat": 35.6581,
          "lng": 139.7013,
          "direction8": "N",
          "distanceKm": 1.81,
          "createdAt": "2025-01-15T10:35:00Z"
        }
      ]
    }
    ```

- **`DELETE /api/favorites/:id`**
  - お気に入りを削除

### 2.3 UI/UX の改善

#### 2.3.1 レスポンシブ対応

- **モバイル対応**

  - 画面幅 768px 以下でモバイルレイアウトに切り替え
  - フォーム要素の幅を調整
  - テーブルを横スクロール可能にする、またはカード形式に変更
  - 地図の高さを調整（モバイル：300px、PC：500px）

- **タブレット対応**
  - 画面幅 768px〜1024px でタブレットレイアウト
  - 2 カラムレイアウトの調整

#### 2.3.2 ローディング表示の改善

- **検索中の表示**

  - スケルトンローディングまたはスピナーを表示
  - 検索中のメッセージを表示（例：「神社・寺院を検索中...」）
  - ボタンを無効化して連続クリックを防止

- **地図読み込み中の表示**
  - 地図エリアにローディングインジケーターを表示
  - 「地図を読み込み中...」メッセージ

#### 2.3.3 エラーハンドリングの改善

- **エラーメッセージの改善**

  - ユーザーフレンドリーなエラーメッセージ
  - エラーの種類に応じた適切なメッセージ：
    - ネットワークエラー：「接続に失敗しました。インターネット接続を確認してください。」
    - 住所が見つからない：「住所が見つかりませんでした。別の住所でお試しください。」
    - API エラー：「サーバーエラーが発生しました。しばらくしてから再度お試しください。」

- **エラー表示の UI**
  - shadcn/ui の`Alert`コンポーネントを使用
  - エラーアイコンを表示
  - エラー詳細を折りたたみ可能にする

#### 2.3.4 テーブル機能の拡張

- **ソート機能**

  - 列ヘッダーをクリックでソート
  - ソート可能な列：名称、距離、方位
  - ソート方向のインジケーター表示（↑↓）

- **フィルタ機能**

  - 方位でフィルタリング（例：N のみ表示）
  - 距離でフィルタリング（例：5km 以内のみ表示）

- **ページネーション**
  - 候補が 20 件以上の場合にページネーションを表示
  - 1 ページあたり 20 件を表示

#### 2.3.5 その他の UI 改善

- **ナビゲーション**

  - ヘッダーに「検索履歴」「お気に入り」へのリンクを追加
  - モバイルではハンバーガーメニュー

- **アクセシビリティ**

  - キーボードナビゲーション対応
  - ARIA ラベルの追加
  - コントラスト比の確認

- **パフォーマンス**
  - 画像の遅延読み込み（Lazy Loading）
  - 地図の遅延読み込み
  - 検索結果の仮想スクロール（大量データ時）

## 3. バックエンド要件

### 3.1 新規 API エンドポイント

#### 3.1.1 検索履歴 API

- **`POST /api/history`**

  - 検索履歴を保存
  - Prisma を使用して`SearchHistory`テーブルに保存
  - バリデーション：必須項目のチェック

- **`GET /api/history`**

  - 検索履歴一覧を取得
  - クエリパラメータ：`limit`（デフォルト：20）
  - 作成日時の降順でソート

- **`DELETE /api/history/:id`**
  - 検索履歴を削除
  - 関連するお気に入りも削除（CASCADE）

#### 3.1.2 お気に入り API

- **`POST /api/favorites`**

  - お気に入りを追加
  - 重複チェック（同じ`searchHistoryId`と`name`の組み合わせ）
  - Prisma を使用して`Favorite`テーブルに保存

- **`GET /api/favorites`**

  - お気に入り一覧を取得
  - 作成日時の降順でソート

- **`DELETE /api/favorites/:id`**

  - お気に入りを削除

- **`GET /api/favorites/check`**
  - お気に入り登録状態を確認
  - クエリパラメータ：`searchHistoryId`, `name`
  - 出力：`{ "isFavorite": true/false }`

### 3.2 既存 API の拡張

- **`POST /api/fortune/recommendations`**
  - レスポンスに検索履歴 ID を含める（オプション）
  - 検索履歴の自動保存オプションを追加
